# 📚 Library Management System

A console-based Library Management System built using **Core Java**. This project helps manage books and students, track book issuing and returning, and store records using file handling.

## 🚀 Features

### Book Management
- Add new books
- Display all books
- Search books by ID
- Issue books to students
- Return issued books
- Check book availability
- Count total books
- Delete books

### Student Management
- Add new students
- Display all students
- Search students
- Delete student records

### File Handling
- Save book records in `books.txt`
- Save student records in `student.txt`
- Load saved records when the application starts
- Maintain data even after closing the application

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Java Collections
- IntelliJ IDEA

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/patidarkavish80-droid/Library-Management-System.git
   ```

2. Open the project in IntelliJ IDEA.

3. Run `Main.java`.

4. Use the console menu to manage books and students.
